# Školní projekty – HTML a CSS

Cvičení z tvorby webových stránek.

| Složka | Téma |
|---|---|
| `muj web/` | Vlastní web o Letohradu: úvod, škola, sport, fotoalbum a formulář. |
| `cviceni_7_z/` | CSS selektory |
| `cviceni_8_z/` | Plovoucí prvky, pozicování (relativní/absolutní), rámečky, rozložení do sloupců |
| `cviceni_9_z/` | Float a clear, overflow, z-index, průhlednost |
| `cviceni_10_z/` | Tabulky, obrázky, flexbox |
| `cviceni_12_z/` | Layout stránky, menu, sloupce |
| `cviceni_13_z/` | CSS Grid |
| `cviceni_14_z/` | Školní web |
| `cviceni_15/` | Formuláře, stránky o ročních obdobích |
| `cviceni_16_z/` | Karta zaměstnance, řidičák |
| `moje prace/`, `recepty/` | Vlastní menší stránky |
